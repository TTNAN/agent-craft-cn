# 真实 Before / After 记录

这个目录用来放**真实**的使用对比：同一段对话/录屏，展示装上 skill 前后 AI 行为的差别。

目前的 README 里"装上前后对比"是**示例场景**（虚构的），说服力有限。等作者（或你）在真实项目里用上这套 skill 后，把对话记录贴到这里，格式建议：

```markdown
## 案例：xxx（日期）

**任务**：一句话描述任务

**Before**（没装 skill）：贴关键对话片段，标出翻车点

**After**（装上 skill）：贴关键对话片段，标出 skill 生效点

**结论**：省了多少返工 / 拦住了什么坑
```

欢迎提 issue 分享你的 before/after，好的案例会收录进 README。
